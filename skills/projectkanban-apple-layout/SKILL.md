---
name: projectkanban-apple-layout
description: Apply Apple-inspired layout and navigation principles to the ProjectKanban web workspace.
---

Use the independent [apple-design-skill repository](https://github.com/SudewaJay/apple-design-skill) for implementation references and [Apple's layout guidelines](https://developer.apple.com/design/human-interface-guidelines/layout) for hierarchy and adaptable layout.

Keep products in a stable navigation area. Put the product title and the primary board action first. Group secondary commands by task, keep integration credentials behind the product owner panel, and keep board scrolling inside the board. Use translucent materials on controls where contrast remains clear. Check keyboard focus, narrow layouts, and long product names.
