---
name: projectkanban-design
description: Design ProjectKanban boards, navigation and sheets using the existing shadcn-style UI.
---

Read the [design and planning guide](../../docs/design-and-planning.md).

1. Identify the user task and inspect the current screen before editing.
2. Reuse Button, Sheet, Lucide icons and CSS tokens. Keep board status visible as text.
3. Prototype consequential layout choices with fictional data. Define empty, loading, error and disabled states.
4. Update the standalone preview when the visible board changes and run projectkanban-design-review.
